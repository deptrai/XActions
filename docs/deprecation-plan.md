# Deprecation Plan — Legacy Scrapers & Clients

> Generated by `bmad-correct-course` Sprint Change Proposal 2026-08-26.
> Cập nhật khi các hybrid crawlers đạt parity và sẵn sàng thay thế.

## 1. Goal

Lập kế hoạch gỡ bỏ an toàn các implementation cũ (legacy) trong XActions sau khi hybrid crawlers (`src/scrapers/social/<platform>/`) đạt đủ parity. Tránh tình trạng 2–3 implementation cùng platform tồn tại song song, giảm rủi ro bảo trì và bundle size.

## 2. Deprecation Criteria

Một module legacy chỉ được xoá khi thỏa mãn **tất cả** các điều kiện sau:

1. Hybrid crawler tương ứng đã `done` và pass tests.
2. Shadow-run parity ≥ 99% trong 7 ngày liên tiếp (Epic 20.1) HOẶC functional parity được xác nhận qua test suite.
3. Tất cả MCP/CLI/API callers được chuyển hướng sang hybrid crawler.
4. `docs/deprecation-plan.md` được cập nhật với trạng thái `removed`.
5. Commit message ghi rõ lý do và danh sách file đã xoá.

## 4. Removal Sequence

### Phase 1 — Deprecation Markers (Epic 13–15)

Thêm `@deprecated` JSDoc và comment `// LEGACY — see docs/deprecation-plan.md` vào:

- `src/client/Scraper.js`
- `src/scrapers/twitter/http/index.js`
- `src/scrapers/twitter/index.js`
- `src/scrapers/facebook/index.js`
- `src/scrapers/threads/index.js`
- `src/cli/commands/checkpoints.js` (redirect note)
- `src/cli/commands/stream.js` (redirect note)

### Phase 2 — Cutover & Shadow-Run (Epic 20.1)

- Chạy Nowing shadow-run với hybrid crawlers.
- So sánh field-level diff giữa legacy và hybrid.
- Không sửa logic legacy; chỉ sửa bug blocker nếu cần.

### Phase 3 — Decommission (Epic 20.2)

Xoá theo thứ tự:

1. `src/client/Scraper.js`
2. `src/scrapers/twitter/http/` (toàn bộ thư mục)
3. `src/scrapers/twitter/index.js` + related files
4. `src/scrapers/facebook/` (toàn bộ thư mục)
5. `src/scrapers/threads/index.js`
6. `src/cli/commands/checkpoints.js` và `src/cli/commands/stream.js` nếu đã merge hoàn toàn vào `admin.js`

### Phase 4 — Cleanup

- Cập nhật `package.json` exports nếu cần.
- Xoá tests legacy tương ứng.
- Chạy `npm run typecheck` và `npm test`.

## 5. Backward Compatibility

- **NFR-16** yêu cầu giữ backward compatibility với `unfollowx` và MCP tools. Do đó, CLI/MCP sẽ không xoá command/tool names, mà redirect sang hybrid implementation.
- `unfollowx` commands được map vào `CrawlerCommand` hoặc trả error `suggestedAction: 'use_x_actions_list'` cho đến khi mapping hoàn tất.
