## Findings

### Bug — fix now

1. **429/403 on a direct (non-proxied) request is masked as PROXY_EXHAUSTED.** `base-client.js:978` throws `XACT_5030` whenever `provider.isAllQuarantined()` — without checking `shouldUseProxy`/`proxy` first — and `ProxyIpPool.isAllQuarantined()` returns `true` on an **empty** pool (`proxy-pool.js:614`, `#proxies.length === 0 → true`). `AbstractApiClient` defaults `proxyPool` to the env-seeded `globalProxyPool`, so when env has no proxies the pool is empty → vacuous-true → every real 429/403 on a direct request surfaces as "Proxy pool exhausted" with `suggestedAction: WAIT`/30 s instead of `RateLimitError`/`BotChallengeError`. Blame: `4d0272ca` (2026-08-20, Epic 11 era) — pre-existing; Epic 35's new client tests are the first to exercise this path. **Currently 7 tests fail on main:** reddit client.test.js (429, 403, RSS-fallback), medium client.test.js (429, 403), instagram client.test.js (429, escalate-to-rotate_proxy). Verified: same failures reproduce on the pre-35.4 baseline (stash-verified earlier in session).
   - Source: `src/core/base-client.js:972-992`, `src/proxy/proxy-pool.js:612-616`, test output 2026-09-12.
   - Proposed fix: gate the exhaustion branch on `shouldUseProxy` (mirroring the pre-flight check at `:705`), and/or make `isAllQuarantined()` return `false` for empty pools.

2. **Vacuous-true `isAllQuarantined()` is a footgun for every future consumer.** Any pool consumer that checks "all quarantined?" before seeding gets `true` on an empty pool. Source: `src/proxy/proxy-pool.js:614`. Disposition: fix together with #1 (empty ⇒ not exhausted).

### Bugs found and fixed inside the epic (record, no action)

3. **`isProxyConnectionError()` missed undici's real dead-proxy shape.** undici wraps socket failures as `TypeError('fetch failed')` with errno on `.cause.code`; the message-only classifier never matched → AC-4's quarantine→direct-retry would have been dead code in production. Caught by the new real-network e2e (`tests/e2e/proxy-injection.e2e.test.js`), fixed in `43e6efbd` by walking `.cause`/`.code` (base-client.js:71-84). Lesson: the `httpClient` seam tests could not surface this — transport-level error shapes need at least one real-network test.
4. **Three latent constructor bugs made injected `proxyPool` silently unused** (all fixed in `a349b526`): subclass ctors forwarding `requiresProxy:false` set `_requiresProxyExplicit` and killed the explicit-proxy route; injected pool stripped from superOptions without setting `_hasExplicitProxy`; Medium's `requiresProxy = false` class field clobbered the option post-`super()`.
