- (decision) Spec created for Scraper Benchmark Suite — a 4-pillar measurement framework (Stability, Quality, Noise, Cost) to grade every scraper in XActions before further development
- (capability) CAP-1: Synthetic Canary Probes — scheduled live probes hitting every scraper with fixed test URLs to measure True Success Rate, P95 latency, checkpoint/ban rate, proxy quarantine rate
- (capability) CAP-2: Production Telemetry Pipeline — hook into AbstractCrawler to record real-run field-fill rate, schema integrity rate, data freshness, latency, proxy bandwidth, account burn, and deduplication noise
- (capability) CAP-3: Benchmark Scoring Engine — compute per-scraper Health Score (0-100) weighted 0.35 Stability + 0.30 Quality + 0.20 Noise + 0.15 Cost, then classify into Tier A/B/C
- (capability) CAP-4: Operator Scorecard & Nowing Guard — CLI , dashboard health matrix, and auto-cutoff of Tier C scrapers from Nowing ingestion to prevent garbage-in
- (capability) CAP-5: Cross-Platform Deduplication Metrics — measure duplicate ratio and contact accuracy (phone/email validation) across multi-platform ingestion
- (constraint) XActions is a dedicated scraping microservice for Nowing (B2B Lead Hub), not a standalone SaaS product — all metrics and thresholds must serve Nowing data-pipeline quality
- (constraint) Benchmark must not require external paid telemetry or APM service — runs within existing Node.js/Prisma/Redis/Bull stack
- (constraint) Must distinguish True Success from False 200 OK (Cloudflare/Arkose/login-walled responses) via platform-specific validators and artifact fingerprinting
- (non-goal) No standalone billing or external customer-facing benchmark API — this spec targets internal Nowing operations and XActions operator dashboards
- (non-goal) No live auto-remediation or self-healing in this scope — benchmark reports and gates, it does not fix selector drift or re-enable quarantined scrapers
- (non-goal) No competitive or market-facing DaaS benchmarking — keep focus on Nowing ingestion health, not external platform ranking
- (assumption) Assumed benchmark cadence: canary probes run hourly on a representative sample of URLs per platform, telemetry collected continuously during production runs
- (question) Does Nowing want the benchmark score to pause ingestion automatically (Tier C cutoff) or only raise operator alerts (human-in-the-loop)?
- (question) Should benchmark include scraping of production data or only dedicated canary URLs to avoid inflating proxy cost?
- (event) Spec kernel authored for Scraper Benchmark Suite — 5 capabilities, 3 constraints, 3 non-goals, 1 assumption, 2 open questions logged; ready for architecture and epic breakdown
- (decision) RESOLVED Q1: Tier C scrapers trigger operator alerts only (human-in-the-loop) — NO automatic ingestion cutoff; Nowing feed continues with warning flag
- (decision) RESOLVED Q2: Benchmark measures production scraping runs (real data) — telemetry from live traffic, not dedicated canary-only URLs; canary probes remain as supplementary stability check
