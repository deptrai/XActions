Forge Report

Tích hợp Jev (TypeSafe AI System One) vào XActions — pressure-tested, hardened.

Kết quả

Ý tưởng HARDENED sau khi verify API surface thật của Jev và đọc code XActions. Điểm then chốt: Jev không phải chat-LLM — nó là decision engine trả typed verdict + calibrated confidence. Vì vậy kiến trúc đúng là Jev làm não quyết định, LLM làm miệng viết — không phải provider drop-in.

Quyết định đã khóa

  • src/agents/jevBrain.js — module riêng, REST fetch tới systemOne, né @typesafe-ai/sdk, reuse retry/rate-limit shell của LLMBrain.
  • Confidence gate per-action, user-tunable — thay magic number score>60/>80/random<0.4.
  • Jev chỉ làm judgment; mọi prose vẫn qua LLMBrain (mid/smart tier).
  • Cơ chế chạm pain X-flag: volume reducer — ít action ngu = ít bot-like.

  • Drop-in Jev làm LLM provider thứ 4 — sai API shape.
